# Data Log: Southern California NFIP Climate Panel

*Southern California NFIP Claims & Climate Panel, 1980–2025, prepared for project file handoff*

Unit of analysis: county–year. Scope: Los Angeles, Orange, Riverside, San Bernardino, San Diego, Santa Barbara, and Ventura counties, 1980–2025 (322 observations). This log lists every variable in socal_nfip_climate_panel.xlsx / .csv in the order it appears in the dataset, with enough detail for an independent analyst to reconstruct the file directly from the original sources. See the accompanying Cleaning Memo for methodology, assumptions, and limitations.

| Variable Name | Description | Original Source | Unit of Measurement | Time Period | Transformations Applied |
| --- | --- | --- | --- | --- | --- |
| county_name | County identifier. One of seven Southern California basin counties in scope: Los Angeles, Orange, Riverside, San Bernardino, San Diego, Santa Barbara, Ventura. | Constructed; county set defined by project team; FIPS codes crosswalked using the California county boundary geodatabase (cnty26_1.gdb, CA State Geoportal). | Categorical (text) | N/A (cross-sectional) | 5-digit county FIPS code mapped to county name; non-target counties dropped. |
| year | Calendar year of observation. | Constructed (panel index). | Year (integer) | 1980–2025 | None. |
| claims_total_paid | Total NFIP claims paid within the county-year. Primary outcome variable. | FEMA National Flood Insurance Program claims transaction file (NfipClaimsV3.csv). | US dollars, nominal | 1980–2025 (year of loss) | Summed amountPaidOnBuildingClaim + amountPaidOnContentsClaim + amountPaidOnIncreasedCostOfComplianceClaim across all claims; aggregated from the individual-claim level to county-year; county-years with no matching claims are coded 0, treating FEMA's file as a complete administrative record of claims paid. |
| claims_n_claims | Count of individual NFIP claims filed within the county-year. | Same as claims_total_paid. | Count | 1980–2025 | Row count per county-year; zero-filled on the same basis as claims_total_paid. |
| active_policies | Total NFIP-insured units active within the county-year. Exposure control variable. | FEMA OpenFEMA NFIP policy-level data (NfipPolicies v3, filtered to the seven target counties via the policy-level censusGeoid field). | Count (insured units) | 2010–2025 | Each policy record's policyCount (insured units; exceeds 1 for RCBAP condo master policies) is attributed to every calendar year its effective-to-termination window overlaps, then summed by county-year. The source data covers policyEffectiveDate 2010 onward; 1980–2009 is coded as missing, not zero, since no source data exists before 2009 and the 2009 figure itself is left-censored and excluded as unreliable. |
| n_policy_records | Count of individual NFIP policy-term records active within the county-year, unweighted by insured units. | Same source as active_policies. | Count (policy-term records) | 2010–2025 | Same construction and coverage as active_policies, counting policy-term records rather than summing policyCount. |
| prcp_inches | Total annual precipitation at the county's assigned weather station. Primary explanatory variable. | NOAA Climate Data Online, Global Summary of the Year (GSOY), station-level. | Inches | 1980–2025 | One representative station selected per county by proximity to the county's population center and period-of-record length, with a secondary station substituted in years the primary station lacked a reading (see prcp_inches_station); each value traces to an actual station reading for that year. |
| prcp_inches_station | NOAA station ID that supplied the prcp_inches value for that county-year. | NOAA station metadata. | Categorical (station ID) | N/A | Provenance field, included for traceability. |
| oni_peak_anom | Highest 3-month-running-mean sea surface temperature anomaly (Niño 3.4 region) recorded during the year, relative to the 1991–2020 baseline. Control variable (ENSO / El Niño–La Niña intensity). | NOAA Climate Prediction Center, Oceanic Niño Index (ONI). | Degrees Celsius (anomaly) | 1980–2025 | 12 overlapping seasonal anomaly values per year collapsed to their annual maximum. Applied uniformly across all seven counties in a given year, consistent with ENSO's status as a regional, basin-wide climate signal. |
| oni_peak_total | Highest raw (non-anomaly) seasonal sea surface temperature recorded during the year. | Same as oni_peak_anom. | Degrees Celsius | 1980–2025 | Annual maximum of the 12 seasonal TOTAL values, reflecting the normal seasonal cycle together with the ENSO signal; retained for reference. |
| oni_min_anom | Lowest (most negative) seasonal SST anomaly during the year; indicates La Niña strength. | Same as oni_peak_anom. | Degrees Celsius (anomaly) | 1980–2025 | Annual minimum of the 12 seasonal anomaly values. |
| oni_peak_abs_anom | Largest seasonal anomaly by absolute value during the year, regardless of sign. | Same as oni_peak_anom. | Degrees Celsius (anomaly) | 1980–2025 | Annual maximum of \|anomaly\| across the 12 seasonal values. |
| wildfire_acres_burned | Total wildfire acreage within the county for the year. Control variable (burn-scar extent). | CAL FIRE / FRAP fire perimeter geodatabase (fire25_1.gdb) intersected with CA county boundaries (cnty26_1.gdb). | Acres | 1980–2025 (fire alarm year) | Spatial (geometric) join of fire perimeter polygons to county polygons in an equal-area projection (NAD83 California Albers, EPSG:3310); each fire's official GIS_ACRES figure apportioned across counties in proportion to the share of its mapped area within each county, then summed by county-year. |
| wildfire_acres_burned_lag1 | Prior-year (t−1) wildfire acreage for the same county. Control variable; proxy for post-fire soil hydrophobicity / debris-flow risk. | Derived from wildfire_acres_burned. | Acres | 1981–2025 (value = year t−1 acreage) | One-year lag within county, sorted by year. Begins in 1981, the first year for which a preceding year's acreage figure exists within the panel. |
| dp01_days | Count of days in the year with precipitation ≥ 0.1 inch. | NOAA GSOY, same station-selection logic as prcp_inches. | Days (count) | 1980–2025 | Same station priority/substitution logic as prcp_inches. |
| dp01_days_station | NOAA station ID that supplied dp01_days. | NOAA station metadata. | Categorical (station ID) | N/A | Provenance field. |
| emxp_inches | Extreme maximum precipitation for the period (single highest-precipitation observation in the year). | NOAA GSOY, same station-selection logic as prcp_inches. | Inches | 1980–2025 | Same station priority/substitution logic as prcp_inches. |
| emxp_inches_station | NOAA station ID that supplied emxp_inches. | NOAA station metadata. | Categorical (station ID) | N/A | Provenance field. |
| awnd_mph | Average wind speed for the year. | NOAA GSOY, same station-selection logic as prcp_inches. | Miles per hour | 1980–2025 | Same station priority/substitution logic as prcp_inches. Wind speed is reported only by automated, airport-class stations, so its coverage follows that narrower set of stations rather than the full precipitation-station list (see Cleaning Memo). |
| awnd_mph_station | NOAA station ID that supplied awnd_mph. | NOAA station metadata. | Categorical (station ID) | N/A | Provenance field. |
